# Dataset 05: MICC-F220 / MICC-F600 — Copy-Move with Geometric Transforms

**Full Name:** MICC-F220 / MICC-F600 — Copy-Move Forgery Dataset  
**Authors:** Amerini, Ballan, Caldelli, et al. (University of Florence, MICC Lab)  
**Year:** 2011 (F220), 2014 (F600)  
**Website:** http://www.micc.unifi.it/resources/micc-f220/ / http://www.micc.unifi.it/resources/micc-f600/  

---

## My First-Person Walkthrough

I went through this dataset because it's **the classic copy-move dataset with geometric transformations** — rotation, scaling, affine distortion. CASIA copy-move is mostly **translation only** (exact duplicate). MICC adds **rotation (up to 180°), scaling (0.5x-2x), combined affine** — this breaks simple block-matching and SIFT-based methods.

When I looked at the details: **F220** = 110 authentic + 110 copy-move (220 total). **F600** = 300 authentic + 300 copy-move (600 total). All **TIFF (uncompressed)** or **JPEG** versions available. Forgeries: region copied from same image, **transformed (rotate/scale/affine)**, pasted back. Ground truth: **binary mask** + **transformation parameters** (angle, scale, matrix) in text file.

The key value: **Known transformation parameters**. You can evaluate: "Does my method detect rotated copy-move at 45°? At 0.7x scale?" This is **controlled geometric robustness testing**. Most DL methods (MFAF-Net, TruFor) handle this via attention/transformers, but classical methods (ECDC, Paper 1) struggle.

On the 2nd iteration, I checked usage: **ECDC (Paper 1)** uses MICC-F220 to test rotation/scale robustness. **DL Survey (Paper 9)** cites it as "copy-move with transforms". For encrypted-domain: **MICC is uncompressed TIFF** (mostly), so like Columbia — compress yourself for JPEG tests. The **known transform params** let you do fine-grained analysis: "Encrypted PP-JPEG detection rate vs rotation angle."

**My takeaway:** MICC = **copy-move geometric robustness benchmark**. Essential if your encrypted method claims to handle transformed copy-move. Use F600 (larger) for testing. Compress at multiple QFs. Evaluate per-transform-type. This is a **specialized but critical** test for copy-move.

## Ground Truth Format

```
# Mask: PNG, white=tampered (source + destination), black=authentic

# Transform params (text file per forged image):
image_id: MICC_F600_001
transform_type: rotation_scale
rotation_angle: 45.0  # degrees
scale_factor: 0.75
affine_matrix: [0.53, -0.53, 0; 0.53, 0.53, 0; 0, 0, 1]
source_bbox: [100, 100, 200, 200]  # x, y, w, h
dest_bbox: [300, 300, 150, 150]
```

## Encrypted-Domain Evaluation Protocol

| Setup | Purpose |
|-------|---------|
| **TIFF → Encrypt** | Uncompressed encrypted copy-move (IFED/LEFN style) |
| **Compress QF=95 → Encrypt** | Near-lossless, minimal artifacts |
| **Compress QF=90 → Encrypt** | Standard test |
| **Compress QF=75 → Encrypt** | Strong artifacts, tests PP-JPEG on transformed CM |
| **Per-transform metrics** | Detection rate vs rotation angle / scale factor |
| **Cross-dataset: Train CASIA → Test MICC** | Geometric generalization test |

## Constraints & Gotchas

- ❌ **Copy-move only** — no splicing, removal, DeepFake
- ❌ **Small (300 forged in F600)** — not for training
- ❌ **Mostly TIFF** — must compress for JPEG tests
- ❌ **Old dataset** — transforms are traditional, not GAN-based
- ❌ **Mask boundary noise** — some pixel inaccuracies
- ✅ **Known transform parameters** — controlled robustness test
- ✅ **Rotation + Scale + Affine** — breaks naive methods
- ✅ **Classic benchmark** — cited by ECDC, DL surveys
- ✅ **Specialized** — fills geometric gap in your portfolio

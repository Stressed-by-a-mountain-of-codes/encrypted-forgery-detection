# Dataset 03: COVERAGE — Large-Scale Diverse Forgery Dataset

**Full Name:** COVERAGE: A Large-Scale Dataset for Image Forgery Detection and Localization  
**Authors:** Wang, Wu, Liu, et al. (Nankai University, etc.)  
**Year:** 2022 (CVPR 2022)  
**Website:** https://github.com/SCLBD/COVERAGE  

---

## My First-Person Walkthrough

I went through this dataset because it's **the largest and most diverse forgery dataset** — 10,000+ images, **multiple forgery types per image**, modern generation methods (GAN, diffusion, traditional). It was created specifically to address the "small, simple forgery" problem of CASIA/Columbia.

When I looked at the composition: **100,000+ authentic images** (from COCO, OpenImages, etc.), **10,000+ forged images** each containing **1-3 forgery types simultaneously** (splicing + copy-move + removal in same image). The forgeries are generated by **8 different methods**: traditional copy-paste, Poisson blending, GAN-based (StyleGAN, DiffuseIT), diffusion-based inpainting, object removal (LaMa, MAT). This is **modern forgery** — not the manual copy-paste of CASIA.

The ground truth is **multi-class pixel-level masks**: 0=authentic, 1=splicing, 2=copy-move, 3=removal. Each forged image has a **JSON metadata** with: forgery types present, source images, transformation params (rotation, scale for copy-move), blending method, generator model. This is **rich annotation** — you can evaluate per-forgery-type.

On the 2nd iteration, I realized: **This is the dataset for generalization testing**. CASIA/Columbia forgeries are "easy" — clear boundaries, simple copy-paste. COVERAGE forgeries have **blended edges, semantic consistency, GAN textures**. A model trained on CASIA will likely **fail hard on COVERAGE**. This is exactly what **CMFDFormer (Paper 7)** and **TruFor (Paper 8)** use for "cross-dataset generalization" experiments.

For my encrypted-domain project: **COVERAGE is the stress test**. If your encrypted method works on CASIA but fails on COVERAGE, it's overfitting to compression artifacts or simple boundaries. The multi-forgery-per-image setup is great for testing **universal detectors** (TruFor-style). But **download is huge** (~10 GB), and you need COCO/OpenImages as authentic source.

**My takeaway:** COVERAGE = **modern, hard, diverse, large-scale**. Use it as **held-out test set only** (don't train on it — use CASIA v2 for training). Evaluate per-forgery-type. If your encrypted method generalizes to COVERAGE, it's actually robust. The metadata lets you do fine-grained analysis: "How does encrypted PP-JPEG do on GAN splicing vs traditional copy-move?"

| Property | Value |
|----------|-------|

| **Format** | JPEG (authentic), JPEG/PNG (forged) |

| **Forged Images** | 10,000+ |

## Forgery Generation Methods (8 Total)

| Method | Type | Description |
|--------|------|-------------|
| Copy-Paste | Splicing/Copy-Move | Traditional hard-edge |
| Poisson Blending | Splicing | Gradient-domain blending |
| StyleGAN | Splicing | GAN-generated patches |
| DiffuseIT | Splicing | Diffusion-based synthesis |
| LaMa | Removal | Large mask inpainting |
| MAT | Removal | Transformer inpainting |
| Copy-Move (Transform) | Copy-Move | Rotation + scale + flip |
| Mixed | All | Multiple types in one image |

## Multi-Class Ground Truth

```
Mask values:
0 = Authentic
1 = Splicing
2 = Copy-Move
3 = Removal (Inpainting)

JSON metadata per forged image:
{
  "image_id": "COV_000123",
  "forgery_types": ["splicing", "removal"],
  "splicing": {"source": "COCO_004567", "method": "StyleGAN", "bbox": [...]},
  "removal": {"method": "LaMa", "mask": [...]},
  "copy_move": null
}
```

## Standard Evaluation (Per COVERAGE Paper)

| Metric | Splicing | Copy-Move | Removal | Overall |
|--------|----------|-----------|---------|---------|
| **mIoU (SOTA)** | ~0.65 | ~0.55 | ~0.45 | ~0.55 |
| **Pixel F1** | ~0.75 | ~0.65 | ~0.55 | ~0.65 |
| **AUC-ROC** | ~0.90 | ~0.85 | ~0.80 | ~0.85 |

> **Note:** Scores much lower than CASIA/Columbia — this is a **hard dataset**.

## Recommended Usage for Your Project

```
# DO NOT TRAIN ON COVERAGE (use CASIA v2 for training)
# Use COVERAGE as HELD-OUT TEST SET only

COVERAGE_test:  2,000 forged + 2,000 authentic (stratified by forgery type)

# Per-type evaluation:
test_splicing:   ~700 images
test_copy_move:  ~600 images
test_removal:    ~500 images
test_mixed:      ~200 images (multiple types)

# For encrypted-domain:
Compress at QF=75/90/95 → Encrypt → Test
```

## Encrypted-Domain Evaluation Protocol

| Setup | Purpose |
|-------|---------|
| **Native JPEG → Encrypt** | Test on modern forgeries with native compression |
| **Re-compress QF=75** | Stronger artifacts, test PP-JPEG |
| **Per-forgery-type metrics** | Does encrypted method fail on GAN splicing? |
| **Mixed forgery images** | Tests universal detection (TruFor-style) |
| **Cross-dataset: Train CASIA → Test COVERAGE** | True generalization test |

## Constraints & Gotchas

- ❌ **Huge download** (~10 GB + authentic sources)
- ❌ **Hard dataset** — expect lower metrics than CASIA
- ❌ **No official train/test split** — create fixed split
- ❌ **Multi-type per image** — evaluation more complex
- ❌ **Modern forgeries** — may not reflect your threat model
- ✅ **Largest, most diverse** — best generalization test
- ✅ **Per-forgery-type masks** — fine-grained analysis
- ✅ **Rich metadata** — source, method, transform known
- ✅ **Used by SOTA (TruFor, CMFDFormer)** — direct comparison

## Relevance to My Project

**Critical held-out test set for generalization:**
- Train on CASIA v2 (encrypted) → Test on COVERAGE (encrypted)
- Per-forgery-type analysis reveals encrypted method weaknesses
- Mixed forgeries test universal encrypted detection
- If it works here, it works in real world
